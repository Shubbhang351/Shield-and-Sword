# 🛡️ Project Shield & Sword

**Shield & Sword** is an offline, privacy-first hybrid Fraud Risk Management (FRM) and Cybersecurity engine. It combines deterministic statistical rules with local and cloud-based LLM agents to detect anomalous retail transactions, suspicious email communications, and security threats in real time.

## 🌟 Core Concept

* **Statistical Rule Layer:** High-speed deterministic filtering for immediate anomaly detection.
* **Local LLM Layer (Ollama):** Offline, privacy-preserving analysis for sensitive payload data.
* **Cloud LLM Layer (Gemini API):** Advanced multi-turn reasoning and complex logic synthesis.
